# 公众号文章批量下载器

一个在微信桌面端里批量导出公众号文章的本地工具。启动后会在本机运行 API 服务和 HTTPS 代理；当用户在微信里打开任意公众号文章页时，代理会向文章页面注入一个“公众号批量下载”面板，用当前文章页里的临时凭证读取该公众号历史文章，并批量保存到本机。

> 只用于归档你本人有权访问的内容。工具不会绕过付费墙；未购买内容只能保存微信实际返回的预览。请遵守版权、平台规则和适用法律。

## 功能

- 从任意可打开的公众号文章页识别公众号信息。
- 分页读取公众号历史文章列表。
- 批量下载文章正文和图片。
- 每篇文章输出三种格式：`html`、`markdown`、`text`。
- 按公众号名称创建子目录，便于归档。
- 支持“已有则跳过”和“覆盖重下”。
- 下载记录显示任务状态、进度、速度和目标路径。

## 原理

工具在本机启动一个 HTTPS 代理，并把系统代理临时指向本机端口。微信打开公众号文章页时，请求会经过本地代理；代理只处理 `mp.weixin.qq.com` 的 HTML 响应，并在文章页注入前端脚本。注入脚本从页面上下文读取公众号 `biz`、临时 token、cookie 等必要信息，然后调用本地 API 分页获取历史消息列表。批量下载时，本地下载器逐篇抓取文章 HTML，解析正文、标题、发布时间和图片资源，再写出 HTML、Markdown、纯文本和图片文件。

公众号首页在微信里通常是原生/内部列表页，不一定经过可注入的 HTML 响应，因此下载入口放在“文章页”里：随便打开该公众号的一篇文章即可读取并批量下载该公众号历史文章。

## 环境要求

- macOS、Windows 或 Linux。
- 已安装微信桌面端。
- 已安装 Go 1.20 或更新版本，用于从源码构建。
- 首次运行需要管理员权限，用于安装/信任本地根证书和设置系统代理。

每台设备首次运行时都会在用户目录生成一套独立根证书与私钥；私钥权限为 `0600`，不会内置在程序或仓库中。本地 API 只接受微信文章页和回环地址来源的浏览器请求。

## 构建

```bash
./build.sh
```

构建产物默认位于：

```text
mp_article_downloader_src/mp_article_batch_downloader
```

## 启动

```bash
./run.sh
```

默认端口：

- API: `127.0.0.1:2122`
- HTTPS 代理: `127.0.0.1:2123`

默认下载目录：

```text
~/Downloads/公众号文章批量下载/<公众号名称>/
```

每个公众号目录下会生成：

```text
html/       # HTML 文件
markdown/   # Markdown 文件和图片
text/       # 纯文本文件
style_corpus.jsonl
```

## 使用方法

1. 运行 `./run.sh`，保持终端窗口不要关闭。
2. 打开微信桌面端。
3. 打开目标公众号的任意一篇文章。
4. 等待页面右下角出现“公众号批量下载”面板。
5. 点击“读取文章”，按需要设置读取页数。
6. 可修改保存子目录，默认是公众号名称。
7. 选择“已有则跳过”或“覆盖重下”。
8. 点击“批量下载”。
9. 点击“下载记录”查看进度和结果。
10. 结束使用时，在终端按 `Ctrl+C` 退出。

## 常见问题

### 为什么公众号首页没有下载按钮？

微信桌面端的公众号首页通常不是普通网页 DOM，当前代理注入方式无法稳定向首页添加按钮。打开任意一篇文章后即可使用批量下载功能。

### 为什么需要管理员权限？

工具需要安装/信任本地根证书，并临时修改系统代理，让微信的公众号文章请求经过本地代理。退出工具时会恢复代理设置。

### 会不会和其他代理软件冲突？

可能会。使用本工具时建议暂停其他会修改系统代理或 TUN 的软件。工具退出后再恢复其他代理。

### 下载失败怎么办？

- 刷新文章页，重新读取文章。
- 减少读取页数后重试。
- 确认微信仍然登录。
- 确认终端里的工具仍在运行。
- 如果端口被占用，先关闭旧进程后再启动。
