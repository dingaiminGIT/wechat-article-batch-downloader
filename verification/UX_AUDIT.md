# 公众号文章下载器 UX 复核

复核时间：2026-09-12 22:44  
方法：在已安装的 macOS 应用中使用 Computer Use 检查当前界面与真实下载结果。

## 1. 开始归档

健康度：良好。

- 首屏把流程收敛为连接微信、打开目标文章、选择范围并归档三步。
- 明确首次证书授权与后续连接的关系，避免用户把每次目录授权误认为必需操作。
- 仍需由微信文章页提供临时凭证；应用会明确显示“打开文章以更新连接”。

## 2. 公众号归档页

健康度：良好，凭证状态清楚。

- 当前实机显示“尚未读取 · 本机已保存 210 篇”，本机数量取实际 Markdown 文件数。
- 读取范围使用“最近文章 / 全部历史 / 日期范围”三段选择，默认“全部历史”。
- 没有读取结果时只提供一个“打开公众号目录”，不会把下载记录或正文塞进当前页。
- 当前凭证过期时，错误和下一步动作同时显示；已保存的文章仍可直接打开。

## 3. 下载速度选择

健康度：良好。

- 设置页提供“安全 / 快速”两种默认速度，安全模式默认选中。
- 有待下载文章时，下载操作区也能在执行前切换速度。
- 快速模式说明包含速度、自动降速重试和持续受限时暂停的行为。

## 4. 下载中心

健康度：良好。

- 每个公众号只占一行批次摘要，显示完成数/总数、失败数、模式、开始与结束时间、总耗时和平均篇数/分钟。
- 实机结果：“每天晒白牙 210/210 篇、快速模式、总耗时 1分53秒、平均 110.7 篇/分钟”。
- 进行中的批次显示 `已完成/总数` 和预计剩余时间；完成后固定显示总耗时。
- 主动作是“打开目录”，下载中心顶部可打开下载根目录。

## 5. 输出与可找回性

健康度：良好。

- 公众号目录仅使用公众号名称，不追加 biz 字符串。
- “每天晒白牙”实测包含 HTML、Markdown、纯文本各 210 篇、210 条唯一 JSONL 记录和 847 张本地图片。
- 《如何将 Agent 等消息触达到微信》位于 Markdown 第 4 篇，可从公众号目录直接找到。

## 可访问性检查范围

本轮通过 macOS Accessibility 树确认主要按钮、单选项、进度条和导航行具有可读名称与状态。未执行 VoiceOver 全流程朗读、键盘焦点顺序和不同显示缩放比例的完整审计。
