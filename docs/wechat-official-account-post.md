# 想研究一个作者的所有文章，我做了一个公众号批量下载器

如果你想认真研究一个作者，最麻烦的往往不是读完某一篇文章，而是先把他散落在公众号里的文章整理到一起。

你可能也遇到过这样的情况：关注一个作者很多年，想回头看看他的观点发生过什么变化；看到一种很喜欢的表达，想分析他的选题、结构和语言习惯；或者只是想把几百篇历史文章放在同一个目录里，统一搜索、阅读和做笔记。

真正动手后，事情很快就会卡住。

公众号适合一篇一篇读，却不太适合成批整理。收藏只能留下链接，搜索很难覆盖一个作者的全部内容。手工复制十篇还能坚持，面对两三百篇文章，光是打开、复制、保存图片和修改文件名，就足以让人放弃。

这个需求并不只属于做技术的人。只要你研究过一个行业、追踪过一个长期写作的作者，或者想为自己的知识库准备一批结构完整的资料，都可能需要同一件事：**把某个公众号的文章完整地放到本地。**

所以，我把之前使用的脚本重新做成了一个 Mac 应用：**公众号文章下载器**。

## 不要求你是公众号管理员

一开始我找过公众号后台的导出能力，但它解决的是“导出自己运营的公众号”。我真正想整理的，往往是别人的文章：技术号、行业号，或者某个持续写作很多年的个人作者。

这个工具不要求你管理目标公众号。

只要这篇文章能够在你的电脑微信里正常打开，就可以从它开始识别公众号，继续读取当前微信账号有权访问的历史文章。最近文章、全部历史和指定日期范围都可以读取，下载过的内容也可以自动跳过。

实际使用只有几步：

1. 打开“公众号文章下载器”，连接电脑微信；
2. 在微信里打开目标公众号的任意一篇文章；
3. 回到应用，选择刚刚识别到的公众号；
4. 选择“全部历史”，读取文章列表；
5. 点击下载，完成后直接打开这个公众号的本地目录。

文章页右侧仍保留了一组“网页内批量下载”按钮，作为旧工具的备用入口。使用新应用时不需要点击它：打开文章后，公众号会自动出现在应用左侧；历史读取和下载都在应用里完成。

每个公众号对应一个同名文件夹。下载中心会显示本次下载的公众号、完成进度、失败数量、开始和结束时间，以及总耗时。它回答的是最实际的三个问题：现在下载到哪了，这次结果怎么样，文件存在哪里。

## 这个功能是怎么实现的

它不是登录公众号管理后台，也不会要求目标作者授权自己的账号。

当你在电脑微信里打开一篇文章时，文章页本身已经带有当前会话能够使用的公众号信息和临时访问凭证。应用在本机识别这些信息，确认文章属于哪个公众号，再按照微信实际返回的分页结果读取历史列表。

读取到列表后，应用会建立本地下载队列。每篇文章的正文只请求一次，同一张图片也只下载一次，然后把解析结果分别交给几种导出格式。已经下载过的文章会通过稳定的文章标识去重，任务中断后也可以从断点继续。

为了兼顾速度和稳定性，我保留了两种模式：

- **安全模式**控制请求节奏，适合文章很多、准备放在后台慢慢归档的情况；
- **快速模式**提高处理速度，遇到短暂访问验证时会自动降速重试。

我用同一个公众号做过一次完整测试：210 篇文章，安全模式用时 3 分 35 秒；快速模式用时 1 分 53 秒，最终 210 篇全部完成，失败 0 篇。

这不是简单地把并发数量调高。请求过快，很容易碰到微信的临时访问限制；过于保守，又会让几百篇文章下载很久。现在的处理方式是在速度和稳定性之间动态调整，而不是把风险留给用户。

## 下载之后能拿到什么

每篇文章会同时保存为四种形式：

- **HTML**：尽量保留原来的排版，适合离线阅读；
- **Markdown**：图片保存在本地，适合 Obsidian、知识库和继续编辑；
- **TXT**：只有正文，适合全文搜索和文本处理；
- **JSONL**：一行一篇，适合批量分析、检索和 AI 语料处理。

如果你的目标是分析写作风格，JSONL 和纯文本可以直接交给后续程序处理；如果只是统一阅读，打开 HTML 或 Markdown 目录就够了。工具不会把你绑定到某个笔记软件，下载完成后，文件就是普通的本地文件。

正文、图片、索引和下载记录都保存在自己的 Mac 上。应用没有云端账号系统，本地服务只监听 `127.0.0.1`。第一次连接微信时，macOS 会要求信任一张在当前电脑生成的证书；证书不变时，后续不需要重复授权。

## 它也有明确的边界

这个工具解决的是批量整理，不是突破内容权限。

付费但尚未购买的文章、已经删除的文章，以及微信限制当前账号访问的内容，工具不会绕过。公众号文章页使用的访问凭证也有有效期；如果凭证失效，重新在电脑微信里打开这个公众号的一篇文章即可更新。

当前版本支持 macOS 14 及以上的 Apple Silicon Mac。安装包还没有完成 Apple 公证，第一次打开时需要在“系统设置 → 隐私与安全性”中确认一次。
